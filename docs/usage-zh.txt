========================================
  Excel 批量文件重命名工具 v3.0（使用说明）
========================================

本版本是 C# 重写版，功能和旧版（Python 版）一致，
但不再是 PyInstaller 打包，杀软误报率大幅下降。

----------------------------------------
一、程序文件
----------------------------------------

ExcelPdfRename.exe   主程序（约 55 KB，无需安装，双击即用）
README.md            版本说明与开发说明
使用说明.txt          本文件

【关于报毒】
旧版是 PyInstaller 单文件包（34 MB），外面套了一层自解压引导器，
个别杀软（Bkav Pro / Elastic / SecureAge）会泛化命中，属于误报。
新版是普通 .NET 程序集，没有自解压、没有壳、没有混淆。
如果仍然有杀软提示，把该文件加白名单即可；
也可以自己用 build.bat 从源码重新编译一份（见 README.md）。

运行环境：Windows 7 SP1 及以上（Windows 10/11 自带 .NET Framework 4.8，
无需另外安装任何东西）。

----------------------------------------
二、Excel 映射改名（主界面）
----------------------------------------

【准备】
Excel 第一行必须是表头，数据从第 2 行开始。
例：
     A 列：编号        B 列：文件编号
     1                 FILE10001
     2                 FILE10002
磁盘上的文件叫 FILE10001.pdf、FILE10002.pdf ……

【操作】
1. 选择 Excel 文件（.xlsx / .xlsm）
2. 选择文件所在文件夹
3. 点【加载 Excel 列】
4. 前缀列选“编号”，旧名字列选“文件编号”
5. 处理行范围：默认从第 2 行到最后一行，行号就是 Excel 左边显示的行号
   （留空=全部；第 1 行是表头）
6. 命名规则：
   - 连接符：前缀和旧名之间的字符，默认 _，支持中文（如 - 第 号_）
   - 扩展名：默认 pdf，可改 docx / jpg 等（不带点，写 .pdf 也行）
   - 前缀补零：0=不补零；填 3 表示 1 → 001
   - 重名处理：跳过 / 自动加序号（xxx(1).pdf）
   - 自动清洗：去首尾空格、把 \ / : * ? " < > | 换成 _
7. 操作模式：
   - 直接改名：原文件被改名（建议先备份）
   - 复制到新文件夹：原文件不动，改名后的副本放进输出文件夹（推荐）
8. 点【预览改名（不改文件）】核对日志
   [OK]   找得到文件，绿色
   [缺失] 磁盘上找不到，红色
   [重名]   新文件名重复，橙色
9. 确认无误后点【执行正式改名】

【命名示例】
连接符 _ ，扩展名 pdf ，前缀补零 3 ：
    前缀=1，旧名=FILE10001   →  001_FILE10001.pdf
连接符 - ，扩展名 docx ：
    前缀=001，旧名=报告       →  001-报告.docx
连接符 第 ，扩展名 pdf ，前缀补零 3 ：
    前缀=1，旧名=章           →  001第章.pdf

----------------------------------------
三、撤销
----------------------------------------

每次执行都会在目标文件夹生成记录文件：
    rename_record_日期_时间.csv   （Excel 映射改名）
    batch_record_日期_时间.csv    （普通批量改名）

撤销步骤：
1. 先在主界面选好“文件所在文件夹”（撤销要用它判断是哪种模式）
2. 点【撤销改名】，选择对应的 csv 记录文件
3. 直接改名模式：把文件名改回原名
   复制模式：删除输出文件夹里的副本，原文件不受影响

----------------------------------------
四、普通批量改名
----------------------------------------

主界面点【普通批量改名】打开独立窗口。

1. 选择文件夹
2. 文件类型：*.pdf  *.docx  *.*（多个用空格分隔）
3. 规则（按顺序执行：查找替换 → 大小写转换 → 加前缀 → 加后缀）
   - 添加前缀 / 添加后缀（后缀加在扩展名之前）
   - 查找 / 替换为，可勾选“正则表达式”
   - 大小写转换：不变 / 全部大写 / 全部小写 / 首字母大写
4. 操作模式、输出文件夹、重名处理 同上
5. 先【预览（不改文件）】，确认后【执行改名】
6. 撤销同上（用 batch_record_*.csv）

示例：
    final report.pdf ，加前缀 2024_ ，查找 final 替换为 最终
    → 2024_最终 report.pdf

    IMG_001.JPG ，查找 IMG_(\d+) 替换为 照片$1（勾选正则），全部小写
    → 照片001.JPG

----------------------------------------
五、注意事项
----------------------------------------

1. 推荐用“复制到新文件夹”，原文件不动最安全
2. 直接改名也请先备份整个文件夹
3. Excel 第一行必须是表头
4. 旧名字列可以带或不带扩展名，程序会自动识别
5. 文件名必须和磁盘上的完全一致（空格、大小写都不能差）
6. 文件正在被其他程序打开时改名会失败，先关掉再试
7. 改完可以用【导出日志】把运行日志存成 txt 留档
